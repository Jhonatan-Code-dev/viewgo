# Rule: Professional Documentation Standards (No Emojis or Graphical Icons)

## Rules & Constraints

1. **No Emojis or Decorative Graphical Icons**:
   - Emojis (e.g. 🌍, ⚡, 🌟, 📦, 📐, 📁, 🚀, 📡, 🏷️, 📄, ❤️, ❌, 🏗️, 🌎, 🕒, 💰, ✔) are strictly forbidden in all project documentation, README files, release notes, pull requests, terminal output, and source code comments.
   - Use standard professional markdown typography, technical headings, tables, clean bullet points, and code snippets.

2. **Corporate Tone & Technical Clarity**:
   - All documentation must maintain an objective, concise, and highly professional corporate software engineering tone suitable for enterprise open-source software and `pkg.go.dev`.
